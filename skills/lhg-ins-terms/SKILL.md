# lhg-ins-terms：条款阅读五查法

> ⚠️ **合规声明（先读）**：本 skill 是**保险条款阅读方法**科普，**非持牌保险建议**；投保前请咨询持牌保险顾问。不评价任何具体产品优劣，只讲阅读方法。

目标：让小白 30 分钟抓住一份条款的要害。核心纪律：**先找"不赔什么"，再看"赔什么"**——保险纠纷九成出在前者。

## 1. 何时使用

- 用户贴出条款文本/产品介绍 → 跑五查全流程
- 用户问"这份重疾险怎么样"→ 不评价好坏，只输出五查对照表，结论用户自己下
- 用户问"等待期是什么意思"→ 单讲第 4 查

## 2. 第一查：健康告知

**查什么**：投保时要回答的健康问卷。

**方法**：
1. 找出告知问卷原文，逐条列出。
2. 标注"问什么答什么"原则：问到的如实答，没问的不用主动说；但"不如实告知"是拒赔第一大原因。
3. 常见高频项：结节/息肉、三高、乙肝、吸烟饮酒史、既往住院手术史、家族病史。

**大白话翻译示例**：
- "过去 2 年是否住院"→ 住过院就写，别赌保险公司查不到。
- "是否曾被拒保/延期/加费"→ 被别家拒过要如实写，隐瞒=埋雷。

**坑点信号**：告知问卷异常宽泛（如"是否有任何身体不适"）→ 提醒用户逐字核对，宁可走人工核保留痕。

## 3. 第二查：免责条款

**查什么**："出现以下情形不赔"的清单，这是整份条款最重要的部分。

**方法**：
1. 逐条摘录免责条款原文。
2. 每条配大白话翻译 + 对用户的影响评级（高/中/低）。
3. 与用户家庭情况交叉：用户从事的职业、常去的地区、已有的健康异常，是否撞上某条免责。

**高频免责情形**（通用知识，具体以条款为准）：
- 投保人/受益人故意行为
- 酒驾、无证驾驶
- 既往症（投保前已患疾病）
- 特定高风险运动（潜水/攀岩/赛车等）
- 战争、核辐射等不可抗力

**坑点信号**：免责条款超过 10 条且含模糊表述（如"其他经认定的情形"）→ 标红，提醒咨询持牌顾问逐条确认。

## 4. 第三查：等待期

**查什么**：投保后多久内出险不赔（或只返保费）。

**方法**：
1. 明确天数：重疾险常见 90/180 天，医疗险常见 30 天，寿险常见 90/180 天，意外险多无等待期。
2. 明确等待期内出险的规则：是"不赔但合同继续"，还是"返还保费合同终止"——两种差别巨大。
3. 明确等待期的起算点：是投保日、承保日还是缴费日。

**坑点信号**：
- 等待期 180 天 + 等待期内出险直接终止合同 → 双重不利，标红。
- 用户已有保单还在等待期，又买同类新保单 → 转交 insurance-check 查 INS-WAIT-001（等待期冲突）。

## 5. 第四查：续保条件（医疗险/意外险命门）

**查什么**：1 年期产品明年还能不能买。

**方法**：
1. 找"保证续保"四个字：有=续保确定性高；没有=每年重新审核。
2. 看续保要不要重新健康告知：要=身体变差可能被拒。
3. 看停售条款：产品停售后能否转投其他产品。
4. 看年龄上限：最高续保到多少岁。

**坑点信号**："本产品为 1 年期，续保需审核"→ 明确告诉用户：理赔过/体检异常后可能买不到，这是 1 年期医疗险的系统性风险，配置时要知情。

## 6. 第五查：理赔流程

**查什么**：真出事了，怎么拿到钱。

**方法**：
1. 报案时限：出险后多少天内要通知保险公司。
2. 材料清单：诊断证明、病历、发票、身份证明等，提前知道=少跑腿。
3. 申请渠道：线上/线下，是否需要原件。
4. 赔付时限：材料齐全后多少个工作日赔付（条款多承诺 30 日内）。

**实用提醒**：就诊时就按"将来要理赔"留材料——病历写全、发票留好、检查报告别丢，比出事再补强 10 倍。

## 8. 高频坑点速查表

| 坑点 | 常出险种 | 条款长相 | 一句话提醒 |
|---|---|---|---|
| 既往症除外 | 医疗/重疾 | 免责条款"被保险人既往症" | 投保前已有的病多不赔，如实告知看核保结论 |
| 等待期 180 天 | 重疾 | "等待期 180 日" | 半年内出险多不赔，买完别觉得"万事大吉" |
| 不保证续保 | 医疗 | "保险期间 1 年，续保需审核" | 明年可能买不到，知情前提下配置 |
| 猝死除外 | 意外 | 免责"猝死"或单独定义 | 程序员/高强度职业必看这一条 |
| 职业类别限制 | 意外 | "1~4 类职业可投" | 5~6 类高危职业先确认可投 |
| 酒驾/无证驾驶除外 | 全险种 | 免责通用项 | 所有保单通用，喝酒不开车 |
| 医院范围限制 | 医疗 | "二级及以上公立医院" | 私立/特需部多不赔（除非条款写明） |
| 既往症+等待期叠加 | 医疗 | 两条同时存在 | 双重过滤，理赔门槛最高的地带 |

**用法**：insurance-term 命令输出坑点清单时，先扫这张表做初筛，再逐条对照条款原文确认。

## 9. 条款黑话翻译词典

| 条款黑话 | 大白话 | 不看懂的后果 |
|---|---|---|
| 保险责任 | 什么情况下赔钱 | 以为"住院就赔"，其实只赔条款列明的情形 |
| 责任免除 | 什么情况下不赔 | 纠纷重灾区，不看等于盲签 |
| 等待期 | 买完多久内出险不赔 | 买完第 10 天确诊，白买 |
| 犹豫期 | 买完 10~15 天内可全额退 | 冲动投保的后悔药，过期再退要扣钱 |
| 现金价值 | 退保能拿回多少钱 | 前几年退保血亏，现金价值表先看 |
| 保单贷款 | 用保单借钱 | 影响保障额度，慎用 |
| 豁免 | 出险后不用再交保费，保障继续 | 有豁免≈多一层安全垫，看清触发条件 |
| 保险金额 | 出险赔多少 | 别和"已交保费"搞混 |
| 保险期间 | 保到什么时候 | 1 年期和终身是两种生物 |
| 交费期间 | 保费分几年交完 | 趸交便宜但压力大，期交贵但灵活 |
| 受益人 | 钱赔给谁 | 不写=法定继承，流程慢 |
| 如实告知 | 有病史要说 | 隐瞒=拒赔，最大雷区 |
| 保证续保 | 明年一定能接着买 | 没有这四个字=每年重新审核 |
| 免赔额 | 多少钱以下不赔 | 1 万免赔额=1 万以内自掏 |
| 既往症 | 买之前就有的病 | 多在免责，带病投保必看 |
| 观察期 | =等待期，另一种叫法 | 同等待期 |
| 全残 | 条款定义的残疾标准 | 不是"不能动"就行，按条款等级来 |
| 猝死 | 条款单独定义 | 有的算意外有的不算，必查 |

## 10. 反模式

- ❌ 只看"赔什么"不看"不赔什么"——纠纷都藏在免责里。
- ❌ 用销售话术代替条款原文——一切以条款 PDF 为准，宣传页不算数。
- ❌ 说"这款产品值得买/不值得买"——我们只做五查对照表，购买决策是用户的，专业判断归持牌顾问。
- ❌ 忽视等待期起算点——差一天出险，结果天差地别。

## 11. 自检与反馈

**质检门**：
- [ ] 五查是否逐项输出，没有跳项
- [ ] 免责条款是否逐条翻译，没有"等"字一笔带过
- [ ] 是否出现"值得买/不值得买"类评价（一出现即返工）
- [ ] 是否出现具体产品推荐/收益率表述（一出现即返工）
- [ ] 开头合规声明是否原样存在

**标准冒烟用例**：输入一份含"等待期 90 天，等待期内出险返还已交保费合同终止"的条款 → 应标出等待期规则，并提示"返还保费终止合同"与"不赔但合同继续"的区别。

**一键反馈**：发现某类条款的新坑点，到本仓库提 issue（标题前缀 `[lhg-ins-terms]`），附条款原文截图文字与坑点描述。
