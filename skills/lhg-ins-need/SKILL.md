# lhg-ins-need：保障需求分析四张表

> ⚠️ **合规声明（先读）**：本 skill 是**保险知识科普**方法论，**非持牌保险建议**；投保前请咨询持牌保险顾问。以下所有口径均为配置思路，不构成购买建议。

目标：把"我家需要买多少保险"变成四张表算出来的缺口数字。核心纪律：**先问全四张表，再算缺口；缺一项就追问，不许脑补**。

## 1. 何时使用

- 用户说"帮我看看家里保险怎么配"→ 全流程（四张表 + 缺口计算）
- 用户已经有一堆保单，想知道"还缺什么"→ 重点跑第 4 步（缺口计算，已有保单先登记）
- 用户只问"重疾险买多少保额"→ 先补问收入与负债，再给口径（第 5 步），不许直接甩数字

## 2. 四张表：一次问全

### 表一：家庭结构表

| 成员 | 年龄 | 职业/风险等级 | 健康状况简述 | 经济角色 |
|---|---|---|---|---|
| 例：丈夫 | 35 | 程序员（低风险） | 体检正常 | 主要收入来源 |
| 例：妻子 | 33 | 教师（低风险） | 甲状腺结节 | 次要收入来源 |
| 例：孩子 | 5 | 学生 | 健康 | 被抚养人 |

**为什么问职业**：意外险费率与职业类别强相关，高空/运输/矿工等高危职业部分险种直接拒保，先问避免白算。
**为什么问健康**：健康告知是投保第一道门，结节/三高/乙肝等常见异常决定"能不能买、加不加费"，提前登记。

### 表二：收入表

- 家庭年收入（税后口径）：____
- 收入稳定性：稳定 / 波动（波动取近 3 年平均 ×0.8 保守口径）
- 主要收入来源占比：____（占比超 70% 的成员是"经济支柱"，保障优先级最高）

### 表三：负债表

- 房贷剩余：____（剩余年限 ____）
- 车贷/消费贷/其他：____
- **负债总额**：____（缺口计算的关键输入）

### 表四：已有保单登记表

| 成员 | 险种 | 保额 | 保障期限 | 缴费中/已缴清 | 状态（生效/等待期/失效） |
|---|---|---|---|---|---|

**登记原则**：公司团险、社保也登记（社保是医疗缺口计算的抵扣项）；已经失效的保单单独标注，不计入有效保额。

## 3. 追问话术（缺项时用）

- 缺收入："方便说一下家庭税后年收入大概范围吗？不用精确到万，区间就行，这是算保额的基数。"
- 缺负债："房贷还剩多少没还？大概就行。负债是寿险保额的第一块拼图。"
- 缺保单："家里现在有保险吗？大概记得哪种、保额多少就行，记不清也没关系，我们先按'没有'算缺口上限。"
- 用户不愿说：尊重，不追问第三遍；改用"假设年收入 X 万"的示例口径演示方法，声明数字仅为演示。

## 4. 四维度缺口计算口径

### 寿险缺口（核心：人不在了，家里钱还够不够）

```
寿险需求保额 = 负债总额 + 5 × 家庭年收入 + 子女教育预留 − 已有寿险保额
```

- "5 年收入"是经验口径：给家庭留出 5 年缓冲期完成收入结构调整。
- 子女教育预留：按"到 22 岁每年 X 万"估算，有就加，没有不强求。
- 结果为负 → 缺口为 0，标记"已覆盖"。

### 重疾缺口（核心：得大病，几年不上班不断粮）

```
重疾需求保额 = 3~5 × 家庭年收入 − 已有重疾保额
```

- 逻辑：重疾险本质是"收入损失补偿"，不是"看病钱"（看病钱归医疗险）。
- 取 3 年还是 5 年：看治疗康复期预估与家庭储蓄厚度，储蓄厚取 3，薄取 5。

### 医疗缺口（核心：大额医疗费封顶）

- 有社保 + 无百万医疗思路保单 → 缺口=1（标记"建议补足医疗思路"）
- 有社保 + 有百万医疗思路保单 → 检查续保条件（转 lhg-ins-terms 第 4 查）
- 无社保 → 缺口放大：医疗险优先级提到重疾险之前

### 意外缺口（核心：意外身故/伤残的兜底）

```
意外需求保额 ≈ 5 × 个人年收入（经济支柱口径）
```

- 伤残按比例赔付是意外险的特点，保额口径可比寿险略低。
- 高危职业：先确认可投保，再谈保额。

## 5. 输出：缺口分析表

| 维度 | 需求保额 | 已有保额 | 缺口 | 优先级 |
|---|---|---|---|---|
| 寿险 | | | | P0（有负债/有娃先行） |
| 重疾 | | | | P0/P1 |
| 医疗 | | | | P0（无社保时） |
| 意外 | | | | P1 |

**优先级规则**：经济支柱的寿险+重疾永远 P0；孩子重疾医疗 P1、寿险最后（孩子不是经济支柱）；先大人后小孩是铁律。

## 6. 实战案例 walkthrough

输入："夫妻 35 岁，丈夫程序员年收入 30 万，妻子教师年收入 10 万，孩子 5 岁，房贷剩余 120 万（20 年），无任何保单，有社保。"

**四张表速填**：
- 家庭结构：丈夫 35（经济支柱，占比 75%）、妻子 33、孩子 5
- 收入：家庭年收入 40 万（税后口径），丈夫为主要收入来源
- 负债：120 万
- 已有保单：无

**缺口计算**：
- 寿险需求 = 120 万 + 5×40 万 = 320 万 → 缺口 320 万（丈夫 P0）
- 重疾需求 = 3~5×40 万 = 120~200 万 → 缺口 120~200 万（夫妻 P0）
- 医疗：有社保但无百万医疗思路保单 → 缺口=1（P0）
- 意外：丈夫约 5×30 万=150 万口径（P1）

**结论一句话**：先给丈夫配 320 万寿险思路 + 夫妻各 50 万重疾思路 + 全家医疗思路，年保费预算上限 4 万。

## 7. 反模式

- ❌ 用户一说收入就直接给"买 50 万重疾"——没问负债和已有保单就下结论，等于闭眼开方。
- ❌ 把"保费预算"当第一步——先算"需要多少保障"，再谈"花多少钱"，顺序反了会系统性买不足。
- ❌ 忽略团险和社保——重复计算缺口，用户多花钱。
- ❌ 给具体产品名——红线，永远只给"险种配置思路"。
- ❌ 谈收益率——保险首先是保障，任何收益话术都属违禁区。

## 8. 自检与反馈

**质检门**（输出前逐项打勾）：
- [ ] 四张表是否问全，缺项是否已追问或声明为假设
- [ ] 四个维度缺口是否都有数字（或"已覆盖"结论）
- [ ] 是否出现具体产品名/收益率表述（一出现即返工）
- [ ] 开头与结尾合规声明是否原样存在

**标准冒烟用例**：输入"夫妻 35 岁、年收入 40 万、房贷 120 万、无保单"→ 寿险缺口应为 120 万 + 200 万 = 320 万；重疾缺口 120~200 万；输出含合规声明。

**一键反馈**：发现口径不合理或缺场景，到本仓库提 issue（标题前缀 `[lhg-ins-need]`），附家庭结构特征与期望口径。
