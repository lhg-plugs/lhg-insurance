# lhg-ins-four：四大险种知识科普

> ⚠️ **合规声明（先读）**：本 skill 是**保险知识科普**，**非持牌保险建议**；投保前请咨询持牌保险顾问。不推荐任何具体产品。

目标：一句话讲清每个险种"保什么、不保什么"，让用户不再把重疾险当医疗险买。核心纪律：**先讲"赔付逻辑"，再讲"怎么选"**。

## 1. 何时使用

- 用户问"重疾险和医疗险有什么区别"→ 直接讲第 2、4 节对照
- 用户问"寿险有必要买吗"→ 讲第 2 节 + "谁需要"判断
- 配置方案里要解释"为什么这样配"→ 引用各节"一句话定位"

## 2. 寿险：人不在了，给家人留钱

**一句话定位**：被保人身故/全残，赔一笔钱给家人，还房贷、养孩子。

| 要点 | 说明 |
|---|---|
| 赔付逻辑 | 身故或全残即赔付，与治疗费用无关 |
| 保什么 | 身故、全残（部分含"生命终末期"提前给付） |
| 不保什么 | 不保疾病治疗、不保生存（纯保障型无生存金） |
| 谁最需要 | 有负债、有未成年子女、配偶无收入的经济支柱 |
| 谁可以暂缓 | 未成年人、单身无负债无赡养压力者 |
| 期限怎么选 | 定期寿险覆盖"责任期"（到孩子成年/房贷还清/退休）；终身寿险贵且多带储蓄属性，科普口径里只讲定期思路 |
| 保额口径 | 见 lhg-ins-need：负债 + 5 年收入 |

**常见误解**："寿险是给自己买的"——错，寿险是给活着的家人买的，自己用不上。

## 3. 重疾险：得大病，补偿几年不上班的收入

**一句话定位**：确诊合同约定的重大疾病，一次性赔一笔钱，弥补收入损失和康复开销。

| 要点 | 说明 |
|---|---|
| 赔付逻辑 | 给付型：达到理赔条件一次性给保额，不问花了多少医药费 |
| 保什么 | 合同列明的重症/轻症/中症（按条款定义，不是医生说的"重病"） |
| 不保什么 | 不保门诊小病、不按发票报销（和医疗险互补） |
| 与医疗险的区别 | 重疾险=收入补偿（定额给付）；医疗险=看病报销（实报实销）。两个都要，不是二选一 |
| 期限怎么选 | 保至 70 岁/终身是常见思路；预算紧可选定期，但注意续保与年龄 |
| 保额口径 | 见 lhg-ins-need：3~5 年家庭年收入 |

**常见误解**："买了重疾险看病就报销了"——错，报销是医疗险的事；重疾险赔的钱是让你安心养病不挣钱的底气。

## 4. 医疗险：看病花了多少，报多少

**一句话定位**：住院/手术等医疗费用，凭发票报销，解决"看不起大病"。

| 要点 | 说明 |
|---|---|
| 赔付逻辑 | 报销型：实报实销，不超过实际花费；有免赔额（常见 1 万） |
| 保什么 | 住院医疗、特殊门诊、住院前后门急诊（以条款为准） |
| 不保什么 | 免赔额以下部分、社保目录外某些项目（看条款）、既往症多在免责 |
| 续保为什么是命门 | 医疗险多为 1 年期；不保证续保的产品，理赔过或身体变差可能买不到下一年——条款五查里续保条件是必查项 |
| 保额口径 | 百万医疗思路是主流形态；保额数字大（百万级）但关键看免赔额与续保 |

**常见误解**："医疗险保额 300 万，比 50 万重疾险划算"——错，两个赛道：一个管报销，一个管收入，缺一不可。

## 5. 意外险：意外身故/伤残的兜底，兼顾小额医疗

**一句话定位**：因意外导致身故/伤残按保额（伤残按比例）赔，意外医疗小额报销。

| 要点 | 说明 |
|---|---|
| 赔付逻辑 | 身故/伤残给付型 + 意外医疗报销型混合 |
| 保什么 | 意外身故、全残、伤残（按伤残等级比例赔）、意外医疗费用 |
| 不保什么 | 不保疾病身故（猝死是否算意外看条款定义，必查） |
| 职业限制 | 1~3 类职业可投是常态，高危职业先确认可投再谈保额 |
| 保额口径 | 经济支柱约 5 年个人年收入；注意"猝死"条款 |

**常见误解**："猝死肯定算意外"——不一定，很多条款把猝死单列或除外，买之前必须看清定义。

## 6. 四险种对照速查

| | 寿险 | 重疾险 | 医疗险 | 意外险 |
|---|---|---|---|---|
| 解决什么问题 | 人不在，家人不断粮 | 大病不上班不断粮 | 大病看得起 | 意外兜底 |
| 赔付方式 | 身故/全残给付 | 确诊给付 | 发票报销 | 身故伤残给付+医疗报销 |
| 保额口径 | 负债+5年收入 | 3~5年收入 | 百万级（看免赔/续保） | 约5年个人收入 |
| 最容易踩的坑 | 给孩子买高保额寿险 | 当医疗险买 | 忽视续保条件 | 忽视职业限制/猝死定义 |

## 7. 选险种决策树：用户只想先买一个，买哪个

```
用户只有一份预算 → 先看身份
├─ 经济支柱（挣钱的人）
│  ├─ 有负债/有娃 → 寿险（定期，覆盖责任期）
│  └─ 无负债 → 重疾险（3~5年收入口径）
├─ 非经济支柱配偶 → 医疗险（百万医疗思路）+ 重疾险
├─ 孩子 → 医疗险 + 重疾险（寿险最后）
└─ 老人 → 医疗险（看健康告知）+ 意外险
```

**使用规则**：决策树只解决"先买哪个"的排序问题，不解决"买多少"；保额回头按 lhg-ins-need 口径算。任何情况下不许跳过健康告知直接谈保额。

## 8. 用户高频问题 10 问

1. **"社保有了，还要买商业保险吗？"**→ 社保有上限（起付线、封顶线、目录限制），商业医疗险补"封顶以上"，重疾险补"收入损失"，寿险社保完全不管。
2. **"重疾险确诊就赔吗？"**→ 看条款定义的理赔条件：有的是确诊即赔，有的要求"实施了某种手术"或"达到某种状态"，逐字看。
3. **"意外险便宜，是不是保额买高点就行？"**→ 意外险便宜是因为出险概率低，保额按 5 年收入口径，不必无限加。
4. **"给父母买重疾险，保费好贵？"**→ 年龄大=费率高且健康告知难过，老人优先医疗+意外，重疾随缘。
5. **"寿险受益人写谁？"**→ 写配偶/子女，写法定继承人等于没写（还要走继承程序）。
6. **"保险期间选 30 年还是终身？"**→ 看责任期：房贷 20 年、孩子 5 岁 → 至少 20 年；终身贵，预算有限先定期。
7. **"体检异常还能买吗？"**→ 看程度：小异常走智能核保（除外/加费承保），大异常可能延期拒保；不如实告知=拒赔，别碰运气。
8. **"两家公司各买一份重疾险，能叠加赔吗？"**→ 重疾险是给付型，可以叠加赔；医疗险是报销型，不能重复报销。
9. **"分红型/万能型能替代保障吗？"**→ 不能。先配齐纯保障型，再谈别的；保障不足时买带理财属性的产品=本末倒置。
10. **"保单买完就不用管了吗？"**→ 每年复查一次：收入、负债、家庭结构变了，保额跟着调；1 年期产品注意续保。

## 9. 一句话记忆卡

- 寿险：人不在，家人不断粮 → 给活着的人买
- 重疾险：大病不上班，不断粮 → 收入损失补偿
- 医疗险：看病花多少报多少 → 发票报销
- 意外险：意外兜底 → 看职业限制和猝死定义
- 共同铁律：先大人后小孩，先保障后其他，不谈收益不点名产品
- 买前三问：健康告知能过吗？免责撞上了吗？等待期多长？
- 买后一查：每年复查一次，保单别买完就忘

## 10. 反模式

- ❌ "四个险种买一个就够了"——四个解决四个不同的问题，互相不替代。
- ❌ 给孩子配高保额寿险——孩子不是经济支柱，寿险优先级最低；先配大人的。
- ❌ 只看保额数字不看条款——50 万保额但免责宽、等待期短，好过 100 万但处处是坑。
- ❌ 把理财型产品当保障买——先配齐保障型，再谈别的；顺序错了等于没穿盔甲先买装饰品。

## 11. 自检与反馈

**质检门**：
- [ ] 每个险种是否讲清"赔付逻辑"（给付 vs 报销）
- [ ] 是否出现具体产品名/收益率表述（一出现即返工）
- [ ] "重疾≠医疗""寿险是给家人买的"等关键区别是否点透
- [ ] 开头合规声明是否原样存在

**标准冒烟用例**：问"重疾险和医疗险都要买吗"→ 应回答"都要"，并讲清给付 vs 报销的区别，不许二选一。

**一键反馈**：发现知识错误或口径过时，到本仓库提 issue（标题前缀 `[lhg-ins-four]`），附条款依据或官方出处。
